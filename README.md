# Say What Actually Broke

One line of software error copy that tells the user the brutal truth: the
database crashed mid-save and took their file with it — then asks them to
upload it again, promising to hold its hand this time. Funny on a single
read, names the real failure, and says what to do next. The program writes
the line to `/output/entry.txt`.
